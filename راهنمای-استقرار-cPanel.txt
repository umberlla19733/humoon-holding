راهنمای استقرار نسخه استاتیک روی cPanel (بدون نیاز به Node.js)
=========================================================

دو فایل زیپ تحویل شده است:
• نسخه کامل (hamun-static-cpanel-YYYYMMDD.zip، حدود ۷۰ مگابایت):
  شامل مدل صوتی آفلاین فارسی؛ جستجوی صوتی و فاکتور صوتی روی همه مرورگرها کار می‌کند.
• نسخه سبک (hamun-static-cpanel-YYYYMMDD-lite.zip، حدود ۱۸ مگابایت):
  بدون مدل آفلاین؛ صوت روی کروم، اج، سافاری و مرورگرهای مبتنی بر Chromium کار می‌کند
  ولی روی فایرفاکس در دسترس نیست.

مراحل استقرار
--------------
۱) وارد cPanel شوید و File Manager را باز کنید.
۲) وارد پوشه public_html شوید (برای ساب‌دامین، پوشه اختصاصی همان ساب‌دامین).
۳) تمام محتویات زیپ را داخل پوشه استخراج کنید
   (index.html باید مستقیم داخل public_html قرار بگیرد، نه در یک زیرپوشه اضافه).
۴) فایل .htaccess مخفی است؛ در File Manager گزینه Settings → Show Hidden Files را فعال کنید.
۵) سایت را با دامنه باز کنید. پنل مدیریت از مسیر:  دامنه شما/#/admin

پشتیبانی صوتی مرورگرها
----------------------
• کروم / اج / اپرا / بریو / سامسونگ اینترنت / سافاری ۱۴.۵ به بالا:
  بدون دانلود اضافه، از موتور داخلی مرورگر (Web Speech) استفاده می‌شود.
• فایرفاکس و سایر مرورگرهای بدون Web Speech:
  موتور آفلاین Vosk داخل مرورگر اجرا می‌شود. در اولین استفاده، مدل فارسی
  (فایل models/vosk-fa/model.tar.gz، حدود ۵۱ مگابایت) یک‌بار دانلود و برای همیشه
  در حافظه مرورگر ذخیره می‌شود؛ دفعات بعد هیچ دانلودی انجام نمی‌شود و هیچ صدایی
  به سرور بیرونی ارسال نمی‌شود (کاملاً آفلاین و محرمانه).
• میکروفون فقط روی HTTPS یا localhost اجازه داده می‌شود؛ روی http ساده مرورگرها میکروفون نمی‌دهند.

محدودیت‌های نسخه استاتیک
------------------------
- مرور و جستجوی هر ۸۰۲۱ کالا، فاکتورها، مشتریان، خزانه و دفتر کل کامل کار می‌کند.
- تغییراتی که در پنل ثبت می‌کنید فقط در مرورگر همان دستگاه (localStorage) ذخیره می‌شوند
  و روی سرور یا سایر دستگاه‌ها منتقل نمی‌شوند (چون سرور Node وجود ندارد).
- فرم استعلام مشتریان از طریق واتساپ/پیامک کار می‌کند؛ ذخیره سرورساید پیام‌ها غیرفعال است.
- درگاه زرین‌پال و ابزارهای هوش مصنوعی که به سرور نیاز دارند در این نسخه غیرفعال‌اند.
- برای فعال‌سازی مجدد این قابلیت‌ها به هاست با Node.js یا یک سرور API جدا نیاز دارید.

به‌روزرسانی داده‌ها
-------------------
برای انتقال نسخه جدید داده، کافی است فایل‌های پوشه data/ را جایگزین کنید
(کش مرورگر کاربران با نسخه جدید حداکثر یک ساعت تازه می‌شود).
